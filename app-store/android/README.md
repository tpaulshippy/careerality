# Google Play Store Assets

This directory contains the Google Play listing assets for Careerality.

## Listing assets

| File | Play Console use | Size or limit |
|------|------------------|---------------|
| `icon.png` | App icon | 512 x 512 px |
| `feature-graphic.png` | Store listing feature graphic | 1024 x 500 px |
| `short_description.txt` | Short description | 80 characters maximum |
| `full_description.txt` | Full description | 4,000 characters maximum |
| `privacy_policy_url.txt` | Privacy policy URL | Public HTTPS URL |
| `support_url.txt` | Support URL | Public HTTPS URL |

## Screenshots

The `screenshots/output/phone/` directory contains five portrait screenshots at
1080 x 1920 px. The `screenshots/output/tablet/` directory contains the same
screens at 2048 x 1536 px for the optional tablet listing.

The screenshots are captured from the same web build used for the iOS assets,
but with Android-sized viewports so the app fills the frame naturally.
