# App Store Screenshots

Place screenshots for App Store Connect in this directory.

## Required sizes

App Store Connect requires screenshots for the following display sizes (PNG or JPEG, no alpha):

### iPhone (required)

| Display | Devices | Resolution (portrait) |
|---------|---------|----------------------|
| 6.9" | iPhone 16 Pro Max | 1320 x 2868 px |
| 6.5" | iPhone 14 Plus, 13 Pro Max, 12 Pro Max, 11 Pro Max, XS Max | 1242 x 2688 px (or 1284 x 2778 px) |

### iPad (required if the app supports iPad)

| Display | Devices | Resolution (portrait) |
|---------|---------|----------------------|
| 13" | iPad Pro (M4) | 2064 x 2752 px |
| 12.9" (2nd gen) | iPad Pro | 2048 x 2732 px |

## Guidelines

- Provide 1–10 screenshots per display size; the first 2–3 appear in search results.
- Show the core experience first: swipe discovery, day-in-the-life card, ROI/salary breakdown, liked careers list.
- Portrait orientation required; landscape is optional (additional set).
- No transparency. Exact pixel dimensions must match one of the sizes above.
- Keep device frames and marketing captions consistent across sizes.
